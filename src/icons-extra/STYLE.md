# Symbols style (extras)
- 24x24 viewBox, no fill on outlines; 2px stroke, round linejoin (round linecap on open marks); no `<text>`.
- Document body is upstream `document.svg` (x5-19, y3-21, 3px fold); marks sit in the lower half (y11-17), 6-8px wide.
- Folder outline is upstream `folder.svg` (x3-21, y5-19); folder-open keeps the same tab and adds a slanted front panel.
- Fills only for solid logos (Figma); all other marks are strokes.
- Paint rule: `mono` = `currentColor` only; `color` = Flexoki 500 hex (+ #878580 neutral outline) only.
